# ADR-007 — Prompts versionados

## Contexto

Uma mudança de prompt precisa passar por revisão de código e poder ser comparada em avaliações. A seção 10.2 do SDD exige uma versão nova quando o texto muda.

## Decisão

Prompts versionados no repositório.

## Consequências

Revisão de código e avaliação por versão. Mudar prompt exige deploy.

## Alternativas

Hub de prompts externo.
