# ADR-012 — Uma réplica da API

## Contexto

A versão 1 evita corrida em tarefas de fundo e facilita a coleta de métricas. A seção 6.5 do SDD descreve o que muda quando houver mais de uma réplica.

## Decisão

Uma réplica da API na versão 1.

## Consequências

Simplicidade. A seção 6.5 descreve a mudança.

## Alternativas

Várias réplicas desde o início.
