# ADR-010 — shadcn/ui sobre Radix

## Contexto

A interface usa um design system escuro, com acessibilidade de base e controle do código dos componentes. A seção 14 do SDD deriva os tokens da imagem de referência.

## Decisão

shadcn/ui sobre Radix com tokens próprios.

## Consequências

Acessibilidade do Radix e controle total do código dos componentes.

## Alternativas

Biblioteca de componentes fechada. Componentes do zero.
